# Disc Duel — Frisbee de Mesa LAN

Jogo Android nativo Java com dois jogadores no mesmo Wi-Fi e modo contra o computador.

## Gerar APK sem instalar programas

1. Baixe `DiscDuel_GitHub_Pronto_Para_Enviar.zip` enviado pelo ChatGPT.
2. Envie **o arquivo ZIP, sem extrair**, para a raiz da branch `main` usando **Add file → Upload files**.
3. O GitHub Actions extrai o projeto, executa o teste TCP e compila o APK.
4. Em **Actions → Gerar APK Android**, após conclusão verde, baixe **DiscDuel-APK** em **Artifacts**. O `app-debug.apk` estará dentro dele.

O APK ainda não foi compilado: o ZIP do projeto precisa ser enviado ao repositório primeiro.
